ซู-ปืนครก — คู่มือใช้งานฉบับย่อ
=================================

โปรแกรมนี้อ่านพิกัดที่เกม WARDOGS แสดงข้างเคอร์เซอร์บนแผนที่ (ตัวเลข y / x)
แล้วคำนวณมุมทิศ (AZ) ระยะ (RNG) และมุมยิง (MIL) ของ L81 / SPH-2
ผลลัพธ์แสดงบน HUD โปร่งใสที่อยู่บนสุดของจอ และเมาส์คลิกทะลุไปถึงเกมได้

ไม่อ่านหน่วยความจำของเกม ไม่ inject ไม่กดปุ่มแทนผู้เล่น ไม่ใช้อินเทอร์เน็ต
ทำแค่จับภาพเล็ก ๆ รอบเคอร์เซอร์ตอนกดคีย์ลัด

เริ่มใช้งาน
-----------
1. ตั้งเกมเป็นโหมด Borderless Windowed (โหมด Exclusive Fullscreen จะมองไม่เห็น HUD)
2. ดับเบิลคลิก ซู-ปืนครก.exe (ครั้งแรกจะเปิดช้าสักครู่เพราะต้องแตกไฟล์)
   ถ้า Windows SmartScreen เตือน ให้กด "More info" > "Run anyway"
3. เปิดแผนที่ในเกม (M) โปรแกรมจะบันทึกตำแหน่งปืนให้อัตโนมัติ
   หรือเอาเมาส์ชี้ที่ตำแหน่งปืนแล้วกด F6
4. ชี้ที่เป้าแล้วกดปุ่มกลางเมาส์
5. อ่าน AZ / RNG / MIL จาก HUD
6. กด F7 เพื่อสลับอาวุธ L81 <-> SPH-2

คีย์ลัด (เปลี่ยนได้ในหน้าตั้งค่า)
----------------------------------
  F6           บันทึกตำแหน่งปืน
  ปุ่มกลางเมาส์  บันทึกเป้า
  M            เปิดแผนที่ + บันทึกตำแหน่งปืนอัตโนมัติ
  F7           สลับอาวุธ (L81 / SPH-2)
  F8           แสดง / ซ่อน HUD
  F9           เปิดหน้าตั้งค่า
  F10          แสดง / ซ่อนไม้บรรทัดศูนย์เล็ง (ต้องเปิดใช้ในหน้าตั้งค่าก่อน)

ความหมายบน HUD
--------------
  L81 / SPH-2   อาวุธที่เลือกอยู่
  AZ            มุมทิศ (เหนือ = 0°, ตะวันออก = 90°)
  RNG           ระยะเป็นเมตร
  MIL           มุมยิงของ L81
  LO / HI       มุมยิงของ SPH-2 แบบวิถีต่ำ / วิถีโค้งสูง
  นอกระยะ       เป้าใกล้หรือไกลเกินระยะยิงของอาวุธนี้

ข้อควรรู้
---------
- MIL คำนวณจากตารางยิงพื้นราบตัวเดียวกับเว็บ wardogs-artillery.com
  ไม่ได้ชดเชยความสูง ถ้าปืนกับเป้าสูงต่างกันมาก ให้ยิงนัดแรกแล้วปรับ
- ถ้าอ่านพิกัดไม่สำเร็จ ตำแหน่งปืน / เป้าเดิมจะไม่เปลี่ยน และ HUD จะบอกสาเหตุ
- ถ้าใช้ UI scale ของเกมต่างจากปกติมาก ให้ไปที่ "วินิจฉัย" > "ตรวจการอ่านพิกัด 1 ครั้ง"
  เพื่อเช็กว่ากรอบ ROI ครอบตัวเลขพอดี
- การตั้งค่าและ log อยู่ที่ %AppData%\SuMortar\

การใช้โปรแกรมนี้เป็นความเสี่ยงของผู้ใช้เอง รวมถึงความเสี่ยงตามข้อกำหนดการใช้งานของเกม
