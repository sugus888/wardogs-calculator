โปรแกรมคำนวณปืนครกแบบ HUD สำหรับ WARDOGS: อ่านพิกัดจากแผนที่ในเกม แล้วแสดง AZ / RNG / MIL

### มีอะไรใหม่ใน V0.4
- **อ่านพิกัดแม่นขึ้น:** เพิ่มตัวอ่านแบบเทียบรูปตัวอักษรที่เรียนจากภาพจริงของจอ 2560×1600 ใช้ตัดสินตอน Tesseract อ่านสองแบบแล้วไม่ตรงกัน (เช่น 3 กับ 5) ทดสอบกับภาพของผู้ทดสอบแล้วอ่านถูกทั้ง 17 กรณีที่เดิมล้มเหลว และจะเลือกได้เฉพาะค่าที่ Tesseract อ่านออกมาอยู่แล้วเท่านั้น
- **กรอบอ่านพิกัดขยายขึ้นด้านบน** เดิมบรรทัด y มักโดนตัด
- **ทิศ (DIR):** ใต้ AZ แสดงทิศ 8 ทิศ + ลูกศร เช่น `E →` ช่วยไม่ให้หลงทิศ ปิดได้ในเมนูด่วน
- **ไม้บรรทัด (F10) แก้แล้ว:** เดิมต้องเปิดในหน้าตั้งค่าก่อน และต้องอ่านพิกัดสักครั้งจึงจะขึ้น ตอนนี้กด F10 ครั้งแรกเปิดใช้และแสดงทันที และมีสวิตช์ในเมนูด่วนด้วย

### มีอะไรใหม่ใน V0.3
- **เมนูด่วน (Insert):** ลอยทับเกม เลือกอาวุธ / ปรับ HUD / ปรับเป้ากลางจอได้ทันที ไม่ต้องย่อจอเกม กด Insert หรือ Esc แล้วกลับเข้าเกม
- **เป้ากลางจอ (F11):** กากบาท / จุด / กากบาท+จุด / วงกลม เลือกสี ขนาด ความหนา ช่องว่าง ความทึบ ขอบดำ และเลื่อนตำแหน่งได้
- **หน้าตั้งค่า (F9) ลอยทับเกม** แล้ว ไม่ต้องย่อจอเกมก่อน
- ใช้ภาษาไทยอย่างเดียวไปก่อน (ปิดภาษาอังกฤษ/จีนไว้)

### มีอะไรใหม่ใน V0.2
- กด **M** แล้วบันทึกตำแหน่งปืนได้บ่อยขึ้น: เริ่มจับภาพช้าลง (250ms) และจับ 7 เฟรมแทน 4 เพราะจาก log ของผู้ทดสอบ เฟรมแรก ๆ แผนที่ยังวาดไม่เสร็จ
  (ถ้าเคยปรับค่า "รอหลังเปิดแผนที่" เอง ค่านั้นจะไม่ถูกเปลี่ยน)
- ถ้า OCR อ่านตัว **x** หรือ **y** หาย แต่ตัวเลขครบ โปรแกรมจะเดาจากลำดับบรรทัด (y อยู่บน x อยู่ล่าง) โดยยังบังคับทศนิยม 2 ตำแหน่งเหมือนเดิม
