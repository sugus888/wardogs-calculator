โปรแกรมคำนวณปืนครกแบบ HUD สำหรับ WARDOGS: อ่านพิกัดจากแผนที่ในเกม แล้วแสดง AZ / RNG / MIL

**ดาวน์โหลด:** ไฟล์ `SuMortar-V*-win-x64.zip` ด้านล่าง แตกไฟล์แล้วดับเบิลคลิก `ซู-ปืนครก.exe`
(Windows 10/11 x64, ไม่ต้องติดตั้ง .NET)

- `F6` / `M` บันทึกตำแหน่งปืน · ปุ่มกลางเมาส์ บันทึกเป้า · `F7` สลับ L81 / SPH-2 · `F8` ซ่อน HUD · `F9` ตั้งค่า
- MIL ใช้ตารางยิงชุดเดียวกับ wardogs-artillery.com (พื้นราบ ไม่ชดเชยความสูง)
- เกมต้องเป็นโหมด Borderless Windowed
- วิธีใช้ฉบับเต็มอยู่ใน `README-th.txt` ในไฟล์ zip
